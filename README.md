# NordiK — Nordic House Builder

NordiK is a premium web application for exploring and designing Nordic-style wood-frame houses. The project showcases various architectural designs inspired by Scandinavian aesthetics, focusing on energy efficiency, sustainability, and modern construction techniques like SIP panels.

## 🚀 Live Demo

The project is deployed and can be viewed at:
[https://nordik-design-studio.lovable.app](https://nordik-design-studio.lovable.app)

## 🛠️ Built With

- **Framework:** [React](https://reactjs.org/) with [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Routing:** [React Router DOM](https://reactrouter.com/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## 💻 Local Development

Follow these instructions to run the project locally on your machine.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd nordik-design-studio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Available Commands

| Command | Description |
| :--- | :--- |
| `npm run dev` | Starts the development server at `http://localhost:8080`. |
| `npm run build` | Compiles the application into the `dist` folder for production. |
| `npm run preview` | Locally previews the production build. |
| `npm run lint` | Runs ESLint to check for code quality and style issues. |
| `npm run test` | Executes unit tests using Vitest. |

## 📁 Project Structure

- `src/pages/`: Contains the main views and house project details (e.g., Helsinki, Tampere, Kuusamo).
- `src/components/`: Reusable UI components built with shadcn/ui.
- `src/hooks/`: Custom React hooks for state and logic.
- `src/lib/`: Shared utilities and configurations.
- `public/`: Static assets like images and global configuration files.
