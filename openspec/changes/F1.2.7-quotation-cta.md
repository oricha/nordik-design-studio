# F1.2.7 - CTA Contextual: "Solicitar Cotización"

**Feature ID:** F1.2.7  
**Epic:** 1.2 - Páginas de Detalle de Producto  
**Status:** in_progress  
**Priority:** critical  
**Effort:** medium (4-6 horas)  

## Descripción
Botones CTA prominentes que abren modal de cotización pre-filled con nombre del proyecto y opción de servicio.

## Criterios de Aceptación
- [x] Botón grande (primary color) en header + final de página
- [x] Click abre modal/página con formulario
- [x] Campo "Proyecto" pre-filled con nombre
- [x] CTAs flotante en mobile

## Cambios Realizados

### 1. Nuevo Componente: `src/components/QuotationModal.tsx`
- Modal de formulario con AnimatePresence
- Campos: nombre, email, teléfono, proyecto (pre-filled), servicio, mensaje
- Validación básica de campos
- Botón submit y close
- Overlay click para cerrar
- Responsive en mobile

### 2. Nuevo Hook: `src/hooks/useQuotationModal.tsx`
- Context para manejar estado del modal
- Funciones: openModal, closeModal, setProjectData
- Accesible desde cualquier componente

### 3. Actualización: `src/components/ProjectDetail.tsx`
- CTA botón en el hero section (después del precio)
- CTA botón al final del CTA Section
- Integración con QuotationModal
- Pre-fill con nombre del proyecto

### 4. Nuevo Componente: `src/components/FloatingQuotationButton.tsx`
- Botón flotante bottom-right en mobile
- Aparece después de scroll > 500px
- Animación de entrada suave
- Click abre modal pre-filled
- Close button o click fuera para cerrar

## Lógica Implementada
- Context API para estado del modal
- Pre-filled project name en formulario
- Validación de email y teléfono
- Overlay click to close
- Floating button con threshold de scroll
- Responsive: solo visible en mobile < 768px
