# F1.1.2 - Filtros Dinámicos con Rango de Precios

**Feature ID:** F1.1.2  
**Epic:** 1.1 - Funcionalidad de Filtros y Búsqueda  
**Status:** in_progress  
**Priority:** critical  
**Effort:** medium (4-8 horas)  

## Descripción
Rango de precios (€0-€400,000) debe actualizarse dinámicamente según los productos filtrados. Los valores min/max se recalculan basados en la categoría seleccionada y otros filtros.

## Criterios de Aceptación
- [x] Rango de precios actualiza al filtrar por tipo
- [x] Valores min/max recalculan dinámicamente
- [x] Input numéricos funcionan con valores actuales
- [x] Rango inicial correcto para cada categoría
- [x] No hay precios fuera del rango disponible

## Cambios Realizados

### 1. Modificación: `src/components/ProjectCatalog.tsx`
- Agregada función `calculatePriceRange()` para calcular min/max dinámicamente
- Agregada función `calculateAvailableRange()` para obtener rango disponible
- Modificado el estado y la lógica de priceRange
- Agregados inputs numéricos para min/max de precio
- El rango se actualiza cuando se cambia la categoría o búsqueda

### 2. Archivos Afectados
- `src/components/ProjectCatalog.tsx` (modificado)

## Lógica Implementada
- Calcula min/max de precios basado en:
  - Categoría seleccionada
  - Búsqueda activa
  - Otros filtros
- Mantiene valores previos dentro del rango válido
- Inputs numéricos para control preciso
- Visualización clara del rango disponible
