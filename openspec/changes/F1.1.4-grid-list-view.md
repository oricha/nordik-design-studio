# F1.1.4 - Vista Grid vs. Lista

**Feature ID:** F1.1.4  
**Epic:** 1.1 - Funcionalidad de Filtros y Búsqueda  
**Status:** in_progress  
**Priority:** critical  
**Effort:** small (1-3 horas)  

## Descripción
Permitir a los usuarios alternar entre visualización en grid (3-4 columnas) o lista (1 fila por proyecto). Estado persiste en sessionStorage.

## Criterios de Aceptación
- [x] 2 botones togglables: Grid/Lista
- [x] Estado persiste en sesión (sessionStorage)
- [x] Responsive en ambas vistas
- [x] Grid: 3-4 columnas según viewport
- [x] Lista: 1 fila con información condensada
- [x] Transiciones suaves entre vistas

## Cambios Realizados

### 1. Modificación: `src/components/ProjectCatalog.tsx`
- Agregado estado `viewMode` (grid/list) con persistencia en sessionStorage
- Agregados botones de toggle con iconos (Grid2X2, List)
- Modificada la clase del grid para cambiar entre vistas
- Agregado CSS para modo lista (flexbox horizontal)
- Estado se guarda y recupera al recargar página

### 2. Archivos Afectados
- `src/components/ProjectCatalog.tsx` (modificado)

## Lógica Implementada
- Estado guardado en `sessionStorage` bajo clave `projectViewMode`
- Al cargar la página, recupera la última vista seleccionada
- Botones con indicador visual de vista activa
- Grid responsivo: 
  - Mobile: 1-2 columnas
  - Tablet: 2-3 columnas
  - Desktop: 3-4 columnas
- Lista: información compacta, mejor para comparación rápida
